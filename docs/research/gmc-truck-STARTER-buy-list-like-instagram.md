## What this setup can do

- Mobile exterior wash (tank + PW + gen)
- Basic interior (shop vac + chemicals + brushes)
- Blow out vents (air compressor) — optional use

## What it cannot do as well as the pro list

- No heated extractor (Mytee)
- No pro polish/ceramic machine (RUPES)
- Smaller gen / cheaper PW = slower, less durable

---

## Buy order
1. Generator + pressure washer + tank + 12V pump  
2. Vac + buckets + chemicals + towels  
3. Hose reel + bottle rack + straps  
4. Compressor only if you want air blow-out
