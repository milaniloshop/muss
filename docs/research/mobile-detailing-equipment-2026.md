## Techniques / workflows tied to tools

1. **Foam → contact wash → spot-free rinse**  
   MJJC/BOSS foam cannon on Kränzle → two-bucket / microfiber mitt → DI rinse (CR Spotless or Blueshine DI fill). Reduces swirl risk and towel time.

2. **Tank + generator mobile independence**  
   65–100 gal PE tank → SHURflo or gravity feed → Kränzle → Champion ~4500W inverter. No customer hose/power required.

3. **Coxreels multi-line van workflow**  
   Separate reels for pressure, vacuum, air, and electrical (as Coxreels documented on Blueshine builds) — cuts setup time and hose tangle between jobs.

4. **Interior upsell stack**  
   Detail Factory pet tools → vacuum → Mytee heated extract → soft brushes for plastics/screens.

5. **Paint correction → ceramic**  
   SCANGRIP Multimatch inspection → RUPES LHR15/21 correction → graphene/ceramic (Gtechniq / Chemical Guys / Adam’s) as sold/done by Paz-style mobile coaters.

## What's trending right now in car detailing (2026)

- **Flow over PSI:** Pros target ~1.8–2.5 GPM at ~1,000–1,300 PSI (Kränzle-class), not house-washing 4,000 PSI units.
- **Spot-free DI / RO+DI:** Mobile fleets fill tanks with DI (Blueshine’s 24/7 fill model); hard-water markets move to RO+DI to stretch resin life.
- **Graphene-hybrid ceramics:** Multi-year “express vs pro” coating menus (Carbon Force, Adam’s Graphene, Gtechniq CSL).
- **Coating maintenance chemistry:** Acidic openers like **CarPro Descale** to revive mineral-clogged ceramics.
- **Twist-loop drying towels (e.g. Rag Company Gauntlet / M22-style):** Safer on coated paint, faster dry, less marring.
- **Turnkey van/truck builds:** Diamond plate, labeled bins, LED work lighting, multi-Coxreel layouts sold as business-in-a-box (Blueshine specialty).
- **Heated extractors as margin tools:** Mytee Lite-class machines unlock interior deep-clean packages beyond vacuum-only.
- **High-CRI portable lighting:** SCANGRIP Multimatch-class lights for correction QC in driveways.
