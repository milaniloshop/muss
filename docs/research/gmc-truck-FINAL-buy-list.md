### Generator note (item 6)
Do **not** buy the old 4500W inverter for Kränzle-alone best practice.

| Tier | Example class | Approx. price | Notes |
|------|---------------|---------------|-------|
| Budget | ~5,500–7,000W **conventional** portable | **~$500–900** | Meets ≥4800W running; louder/heavier |
| Mid | Dual-fuel ~6250–7000W class | **~$700–1,200** | Common mobile choice |
| Quiet premium | Honda EU7000iS (~5500W rated) | **~$4,900** | Quiet; heavy (~260 lb); verify Kränzle surge OK |

Run **Kränzle alone** on the gen. Mytee and RUPES run **separately**.
