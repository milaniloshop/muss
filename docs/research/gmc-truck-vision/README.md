
## 6 zones (quick map)

1. **Water** — 100-gal tank + DI fill  
2. **Power** — Champion 4500W inverter  
3. **Wash** — Kränzle + SHURflo + MJJC foam cannon  
4. **Reels** — Dual Coxreels (pressure + rinse)  
5. **Interior** — Mytee Lite 8070  
6. **Finish** — RUPES, SCANGRIP, Detail Factory, towels, chemicals
