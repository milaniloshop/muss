# GMC Truck Detailing — Buy List (Taobao vs Amazon)

Use this list to buy **only** what matches the GMC truck designs you liked.  
Compare price + shipping + voltage (US 110V vs China 220V) before ordering.

**Tech Q&A (hot water, reclaim, flow, payload, bed, power):** see [`gmc-truck-followup-answers.md`](./gmc-truck-followup-answers.md)  
**Key updates from that Q&A:** exterior stays **cold-water**; SHURflo is for **rinse reel** (Kränzle self-primes); generator should be **≥4800W running**; tools run **sequentially**.

**How to use Taobao links:** they open a search for the product / closest equivalent. Sort by sales + store rating, then check: voltage, PSI/GPM, fittings, warranty.

**Legend**
- ✅ Exact / same brand model often available  
- ≈ Closest equivalent (not identical SKU)  
- Qty = what the design needs

## Buy order (recommended)

1. **Tank + pump + generator + washer + 2 reels** → truck can wash outside  
2. **Foam cannon + wand rack + chemical rack** → real workflow speed  
3. **Mytee + brushes + towels** → interior packages  
4. **RUPES + SCANGRIP + coating** → polish / ceramic upsells  
5. **DI system** only if you can’t fill spot-free water elsewhere  

---

## Compare checklist (before you click buy)

- [ ] Voltage: generator country + washer/extractor must match (**110V vs 220V**)  
- [ ] Washer flow: prefer **~1.6–2.0 GPM**, not 4 GPM house washers  
- [ ] Foam cannon **fitting** matches Kränzle / your gun  
- [ ] Reel pressure rating ≥ **3000–4000 PSI** for pressure line  
- [ ] Tank outlet size matches pump hose (usually **¾" / ½"**)  
- [ ] Add shipping + import tax into Taobao total vs Amazon Prime price
